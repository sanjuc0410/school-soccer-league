# ⚽ 학교 축구 리그 관리

전교생이 신청해서 랜덤으로 팀을 나누는 축구 리그를 운영하는 프로그램입니다.
**서버가 필요 없는 HTML 파일 하나**라서, 내려받아 더블클릭하거나 GitHub Pages 주소로 열면 바로 쓸 수 있습니다.

## 주요 기능

| 단계 | 기능 |
|---|---|
| ① 대회 | 경기 방식 선택: **풀리그 / 리그 후 토너먼트 / 조별리그 + 토너먼트**, 팀 수(2~16), 팀 이름·색, 승점, 경고 누적 기준 |
| ② 선수·팀 편성 | 신청 명단 붙여넣기 또는 CSV 불러오기 → **랜덤 팀 편성**(팀 인원 차이 최대 1명), 직접 옮기기, 팀 확정 잠금 |
| ③ 심판 | 심판 명단 등록, **자동 배정**(배정 횟수 균등, 경기하는 팀 선수는 제외), 배정 현황 |
| ④ 경기 일정·기록 | 라운드별 일정 자동 생성, 조 추첨, 경기마다 날짜·시간·장소·심판 입력, **득점·도움·자책골·경고·퇴장** 기록, 토너먼트 승부차기 |
| ⏱ 경기 진행 화면 | 경기마다 **▶ 진행** 버튼: 출전 선수 체크 → 경기장에 **포지션별 배치**(5·7·8·11명), 이름을 **터치**해 골·도움·파울·경고·퇴장·자책골 기록, 끌어서 자리 이동, 교체, **줄어드는 경기 시계**(전·후반, 추가 시간 표시), **종료 알람**(진동·호각·화면 깜빡임) |
| ⑤ 순위표 | 승점 → 골득실 → 다득점 → 페어플레이 순, 조별 순위, 토너먼트 대진표, 우승·준우승·3위 |
| ⑥ 개인 기록 | 득점·도움·공격포인트 순위, **출전정지 대상**(퇴장·경고 누적), 경고·퇴장 기록, 심판 활동 기록 |
| 💾 백업·연결 | **구글 시트 연결(PC·휴대폰 함께 쓰기)**, 전체 백업 파일 내려받기/불러오기, 팀 명단·경기 결과·개인 기록 CSV(엑셀), 화면별 인쇄 |

## 사용 방법

1. `index.html`을 크롬이나 엣지로 엽니다. (GitHub Pages에 올렸다면 그 주소로 접속)
2. **① 대회** 탭에서 새 대회를 만듭니다.
3. **② 선수·팀 편성** 탭에 신청 명단을 붙여넣고 `🎲 전체 랜덤 편성`을 누릅니다.
   - 한 줄에 한 명: `학년 반 번호 이름` (예: `2 3 15 학생A`), 이름만 적어도 됩니다.
4. **③ 심판** 탭에 심판 명단을 넣습니다.
5. **④ 경기 일정·기록** 탭에서 일정을 만들고, ③ 탭으로 돌아가 `자동 배정`을 누릅니다.
6. 경기가 끝날 때마다 `기록` → 득점·경고 입력 → `✅ 경기 종료`를 누릅니다.
7. 리그(또는 조별리그)가 끝나면 `🏆 토너먼트 대진 만들기`를 누릅니다.

### 출전정지 규칙 (기본값)
- 퇴장(또는 한 경기 경고 2회) → 다음 1경기 출전정지
- 경고 2회 누적 → 다음 1경기 출전정지 후 누적 초기화 (① 대회 탭에서 3회/적용 안 함으로 변경 가능)
- 파울 5회 누적 → 다음 1경기 출전정지 후 누적 초기화 (① 대회 탭 "경기 진행 화면 설정"에서 변경 가능)
- 출전정지 선수는 경기 진행 화면의 출전 선수 체크가 자동으로 막힙니다.

### ⏱ 경기 진행 화면 쓰는 법
1. **④ 경기 일정·기록** 탭에서 경기 옆 **▶ 진행** 을 누릅니다.
2. **① 출전 선수**: 오늘 나온 선수를 체크합니다. 체크한 순서대로 선발이 경기장에 배치되고, 넘치는 인원은 교체 선수가 됩니다. (명단에 없는 선수는 이름을 바로 추가)
3. **② 경기장**: **▶ 시작** 으로 시계를 켭니다. 선수 이름을 **누르면** 기록 메뉴(골·파울·경고·퇴장·자책골)가 나오고, 골을 누르면 도움 선수를 고릅니다. 기록 시간(분)은 시계에서 자동으로 들어갑니다.
4. 이름을 **끌면** 자리를 옮기고, 같은 팀 선수 위에 놓으면 자리를 맞바꿉니다. 교체 선수를 누르면 **교체 투입** 할 수 있습니다.
5. 정해진 시간이 되면 알람이 울리고, 시계가 **+0:30** 처럼 추가 시간을 표시합니다. 전·후반 경기는 **후반 시작 준비** 를 누른 뒤 다시 **▶ 시작**.
6. 끝나면 **✅ 경기 종료** 를 누르면 순위표와 개인 기록(득점·도움·파울·출전 경기 수)에 반영됩니다.

## ☁️ 구글 시트 연결하기 (PC·휴대폰 함께 쓰기)

연결하면 PC와 휴대폰 어디서 고쳐도 같은 기록이 보입니다. 처음 한 번만 설정하면 됩니다. (약 10분)

### 1단계. 구글 시트 만들기
1. 구글에 로그인하고 [sheets.new](https://sheets.new) 로 새 시트를 만듭니다. 이름은 예: `축구리그 기록`.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 원래 있던 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 전부 복사해 붙여넣은 뒤 💾 저장합니다.

### 2단계. 접속 코드 만들기
1. 시트 화면으로 돌아와 **새로고침(F5)** 하면 메뉴에 **⚽ 축구리그** 가 생깁니다.
2. **⚽ 축구리그 → 접속 코드 만들기 / 바꾸기** 를 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 계정 선택 → (경고가 나오면) **고급 → 이동** → **허용**.
3. 화면에 나온 10자리 **접속 코드**를 적어 둡니다. (나중에 **접속 코드 확인** 메뉴로 다시 볼 수 있습니다)

### 3단계. 웹 앱으로 배포하기
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자** 로 정하고 **배포** 를 누릅니다.
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자" 항목이 없으면 학교(교육청) 계정 정책으로 막혀 있는 것입니다. 정보 담당 선생님께 문의하세요.
> 접속 코드가 있어야 기록을 읽고 쓸 수 있으므로, 주소만 알아서는 기록을 볼 수 없습니다.

### 4단계. 프로그램에 연결하기
1. PC에서 프로그램을 열고 **💾 백업·연결** 탭 → **구글 시트 연결** 에 웹 앱 URL과 접속 코드를 넣고 **연결하기** 를 누릅니다.
   - PC에 이미 만든 대회가 있으면 시트로 올라갑니다.
2. **📱 휴대폰 연결 링크 복사** 를 눌러 카카오톡 "나와의 채팅" 등으로 휴대폰에 보냅니다.
3. 휴대폰에서 그 링크를 열면 자동으로 연결됩니다. 브라우저 메뉴의 **홈 화면에 추가** 를 누르면 앱처럼 쓸 수 있습니다.

### 연결 후 알아 둘 점
- 오른쪽 위에 **☁️ 온라인 저장됨** 이 보이면 정상입니다.
- 인터넷이 끊기면 **⚠️ 인터넷 연결 안 됨** 이 표시되고, 기기에 먼저 저장했다가 연결되면 자동으로 올립니다.
- 다른 기기에서 고친 내용은 20초마다(또는 화면을 다시 열 때) 받아옵니다. 두 기기에서 서로 다른 경기를 동시에 기록해도 자동으로 합쳐집니다.
- 시트의 **경기결과** 탭에서 날짜·점수·득점자·경고를 표로 볼 수 있습니다. (보기 전용, 여기서 고친 내용은 프로그램에 반영되지 않음)
- 접속 코드가 알려졌다면 **⚽ 축구리그 → 접속 코드 만들기 / 바꾸기** 로 바꾸고, 각 기기에서 다시 연결하세요.

## ⚠️ 데이터 저장에 관한 주의

- 구글 시트에 연결하지 않으면 기록은 **그 기기의 브라우저 안(localStorage)** 에만 저장됩니다. 다른 기기에서는 보이지 않고, 브라우저 사이트 데이터를 지우면 사라집니다.
- 연결 여부와 관계없이 **대회가 끝나면 [💾 백업·연결] 탭에서 백업 파일을 한 번 받아 두세요.**

## 🔒 개인정보 보호

- 이 저장소에는 **프로그램 코드만** 올립니다. 웹 앱 URL과 접속 코드도 코드에 적지 않고 각 기기의 브라우저에만 저장됩니다.
- 학생 이름이 들어 있는 백업 파일(`.json`)이나 명단(`.csv`)은 절대 올리지 마세요.
- `.gitignore`에 `*.json`, `*.csv`, `*.xlsx`를 넣어 두어 실수로 올라가지 않게 했습니다.
- 구글 시트에 연결하면 학생 이름이 선생님 구글 계정의 시트에 저장됩니다. 학교의 개인정보 처리 기준에 맞는 계정을 사용하세요.
- 백업 파일은 학교 업무용 PC나 교육청이 허용한 저장소에만 보관하세요.

## GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages** 로 이동합니다.
2. Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 Save를 누릅니다.
3. 1~2분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 주소로 열 수 있습니다.

주소를 공유해도 각자 자기 브라우저에 따로 저장되므로, 다른 사람이 내 기록을 보거나 바꿀 수는 없습니다.
